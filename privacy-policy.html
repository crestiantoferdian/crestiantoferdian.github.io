Kebijakan Privasi LesLesanKu

Berlaku untuk aplikasi LesLesanKu (LLK) — aplikasi manajemen absensi, jadwal, dan progres siswa untuk tutor privat.

Terakhir diperbarui: 4 September 2026

LesLesanKu ("Aplikasi") dikembangkan dan dikelola secara independen oleh tutor pemilik aplikasi ini ("Pengembang", "kami"). Kebijakan ini menjelaskan data apa saja yang dikumpulkan Aplikasi, bagaimana data itu disimpan dan digunakan, serta hak yang kamu miliki atas data tersebut.

1. Siapa yang menggunakan Aplikasi ini

Aplikasi ini dipakai oleh tutor/pengajar privat untuk mencatat kehadiran, jadwal, progres belajar, dan pembayaran siswa les mereka sendiri. Aplikasi ini bukan platform publik untuk siswa atau orang tua — data siswa yang tercatat di dalamnya dimasukkan sendiri oleh tutor sebagai bagian dari catatan mengajarnya, bukan diserahkan langsung oleh siswa ke Aplikasi.

2. Data yang dikumpulkan

a. Data akun (kalau memilih login dengan Google)

Aplikasi menyediakan opsi login memakai akun Google. Ini bersifat opsional — Aplikasi tetap bisa dipakai sepenuhnya tanpa login, dengan data tersimpan hanya di perangkat. Kalau kamu memilih login, kami menerima dari Google:

  • Nama dan alamat email akun Google kamu
  • Foto profil Google kamu (kalau ada)
  • ID unik akun (dipakai untuk mengaitkan data cadangan ke akunmu)

b. Data yang dimasukkan tutor ke dalam Aplikasi

Ini adalah data operasional yang diketik/diisi sendiri oleh tutor:

  • Nama siswa, mata pelajaran/instrumen, dan jadwal les
  • Nomor WhatsApp siswa/orang tua (opsional, kalau diisi tutor)
  • Riwayat kehadiran (hadir/izin/alpa) per sesi
  • Catatan progres belajar per pertemuan
  • Daftar kurikulum/topik dan status penguasaannya per siswa
  • Riwayat dan status pembayaran les
  • Pengaturan Aplikasi (nama sekolah/tempat les, logo, tema warna, dll)

c. Data teknis notifikasi

Kalau kamu mengaktifkan notifikasi pengingat jadwal, Aplikasi menyimpan ID langganan notifikasi (subscription ID) dari layanan pihak ketiga OneSignal, untuk mengirim pengingat ke perangkatmu. Aplikasi tidak mengakses kontak, lokasi, kamera, atau data pribadi lain di HP-mu.

3. Bagaimana dan di mana data disimpan

KondisiTempat penyimpanan
Tanpa login (mode lokal)Hanya di penyimpanan lokal perangkat (localStorage browser/HP). Tidak dikirim ke server manapun.
Setelah login dengan GoogleDisimpan lokal di perangkat dan disalin otomatis ke Cloud Firestore (Google Firebase), sebagai cadangan yang terikat ke akun Google-mu.

Data cloud disimpan di server Google Cloud (Firebase) yang berlokasi di kawasan Asia Tenggara. Data hanya bisa diakses lewat akun Google yang sama dengan yang dipakai untuk login — Aplikasi menerapkan aturan keamanan (security rules) di sisi server yang menolak semua akses selain dari pemilik akun tersebut.

4. Layanan pihak ketiga yang digunakan

Aplikasi memakai beberapa layanan pihak ketiga untuk menjalankan fiturnya. Kami tidak menjual atau membagikan data ke pihak lain untuk kepentingan iklan atau komersial.

LayananFungsi
Google FirebaseLogin akun (Authentication) dan penyimpanan data cadangan cloud (Firestore)
OneSignalPengiriman notifikasi pengingat jadwal
Cloudflare WorkersPerantara teknis yang meneruskan permintaan notifikasi ke OneSignal secara aman
GitHub PagesHosting/penyedia halaman web Aplikasi

Masing-masing layanan di atas punya kebijakan privasinya sendiri sebagai penyedia infrastruktur teknis.

5. Data siswa dan pengguna di bawah umur

Aplikasi ini adalah alat bantu administrasi untuk tutor, bukan layanan yang ditujukan langsung untuk digunakan oleh anak-anak. Siswa (termasuk yang berusia di bawah 18 tahun) tidak berinteraksi langsung dengan Aplikasi — data mereka dicatat oleh tutor sebagai bagian dari administrasi kegiatan les. Tutor bertanggung jawab untuk memastikan pencatatan data siswa (termasuk siswa di bawah umur) dilakukan sesuai persetujuan yang relevan dari siswa/orang tua atau wali, sesuai konteks les privat masing-masing.

6. Berapa lama data disimpan

Data lokal tersimpan selama Aplikasi tidak dihapus (uninstall) atau data browser tidak dibersihkan. Data cloud tersimpan selama akun Google kamu tetap terhubung ke Aplikasi. Kamu bisa meminta penghapusan data cloud kapan saja lewat kontak di bagian bawah halaman ini.

7. Hak kamu atas data

  • Akses & ekspor: semua data bisa diekspor kapan saja lewat fitur "Backup Data Manual" di dalam Aplikasi (menghasilkan file yang bisa dibuka/dibaca).
  • Koreksi: semua data bisa diedit langsung di dalam Aplikasi kapan saja.
  • Penghapusan: data lokal terhapus otomatis saat Aplikasi di-uninstall. Untuk menghapus data cloud (Firestore) secara permanen, hubungi kami lewat kontak di bawah.
  • Logout: logout dari akun Google berhenti menyinkronkan data baru ke cloud, tapi tidak menghapus data yang sudah tersimpan di cloud sebelumnya.

8. Keamanan data

Semua komunikasi antara Aplikasi dan server memakai koneksi terenkripsi (HTTPS). Data cloud dilindungi aturan akses yang hanya mengizinkan pemilik akun membaca/menulis datanya sendiri. Meski begitu, tidak ada sistem yang bisa menjamin keamanan absolut 100% — kami menyarankan menjaga keamanan akun Google kamu sendiri (mengaktifkan verifikasi 2 langkah, dll).

9. Perubahan pada kebijakan ini

Kebijakan ini bisa diperbarui sewaktu-waktu mengikuti perubahan fitur Aplikasi. Tanggal "Terakhir diperbarui" di bagian atas halaman ini akan disesuaikan setiap kali ada perubahan berarti.
